# Анализ референсного шаблона `338535-00-90-000 ПЭ3.xlsx` (Этап 0)

Метод анализа: распаковка OOXML (zip → sheetN.xml, workbook.xml, sharedStrings.xml).
Данные подтверждены на реальном файле из репозитория.

## 1. Листы книги (порядок в workbook.xml)

| # | Имя листа | sheetId | Назначение |
|---|-----------|---------|------------|
| 1 | `Для печати` | 12 | Готовая страница №1 (шапка-лист): ссылки на `Таблица!A11…D38` |
| 2 | `Таблица` | 10 | Источник данных (в эталоне пуста — заполняется библиотекой) |
| 3 | `Info` | 14 | Метаданные документа (адресаты глобальных имён) |
| 4 | `Шаблон листа` | 13 | Шаблон для тиражирования страниц 2..N: ссылки на `Таблица!A2…D32` |

## 2. Ссылки шаблонов на источник (`=Таблица!`)

Подсчёт по **уникальным строкам источника** (не по номеру последней строки листа!):

| Лист | Формул `=Таблица!` | Столбцы источника | Строки источника | Уникальных строк = строк данных на странице |
|------|--------------------|-------------------|------------------|---------------------------------------------|
| `Для печати` | 112 (4×28) | A,B,C,D → D,H,N,S | 11…38 | **28** |
| `Шаблон листа` | 124 (4×31) | A,B,C,D → D,H,N,S | 2…32 | **31** |

Вывод: 28 ≠ 31 — параметр «строк на страницу» обязан определяться автоматически
из конкретного шаблона (первый лист и повторяемый шаблон имеют разную ёмкость).

## 3. Ячейка номера листа и формула пагинации

- Лист `Шаблон листа`: маркер `Лист` в **T33**, номер листа — формула в **T34**:
  `=((ROW(A1)-1-38)/35)+2`
- Константы формулы расшифровываются так: знаменатель **35** = высота блока страницы
  шаблона (строки 1–35), сдвиг **38** = строки первого листа до начала его блока (37) + 1,
  стартовое смещение **+2** = первый повторный лист имеет номер 2.
- На `Для печати` номер зафиксирован константой: `R34 = 1`, общее число листов `T34 = =SheetsNumber`.
- При копировании листа формула `ROW(A1)` не меняется → после создания каждого нового листа
  библиотека должна переписать формулу номера явно (номер k → `=((ROW(A1)-1-{offset})/{height})+{k}`
  или эквивалентная константа/формула).

## 6. Структура листа `Таблица`

- Строка 10 — заголовок таблицы (`_FilterDatabase A10:E10`); данные размещаются со строки 11
  (лист `Для печати` ссылается на A11), тогда как `Шаблон листа` ссылается на A2 —
  различие стартовых строк учитывается автоопределением: считаем **множество уникальных
  строк источника** всех формул вида `=<ЛистИсточник>!`.
- Колонки источника: A=Поз., B=Обозначение, C=Кол., D=Примечание (+E в фильтре).

## 7. Прочее

- PrinterSettings: 4 бинарных файла (по одному на лист) — настройки печати наследуются при Copy.
- Формула J33 `=NameMain & CHAR(10) & NameAdd & CHAR(10) & DocName` — склейка из глобальных имён.
- `Info!B15 (SheetsNumber) = 1` в эталоне — значение должно пересчитываться при пагинации.

## 8. Выводы для реализации (подтверждение пунктов плана)

1. Rows-per-page считать по количеству **уникальных ячеек строки источника** в формулах
   `=Таблица!` (28 и 31 подтверждены), а не по последней строке листа. ✔ п.0.1.6
2. Стартовая строка источника различается между первым листом (11) и шаблоном (2) —
   при расчёте страниц использовать собственное множество строк соответствующего листа. ✔ этап 8
3. Формула номера листа содержит параметры offset/height/start — извлекаются из шаблона
   регэкспом и переписываются для каждой копии. ✔ этап 9
4. Обновление `SheetsNumber` — через глобальное имя `Info!$B$15`. ✔ этап 4/9
