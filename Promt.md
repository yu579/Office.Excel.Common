## 1. Задача и контекст
Разработать библиотеку на C# (LangVersion 9) для работы с Excel через COM Interop.
Библиотека инкапсулирует создание/закрытие COM-объектов, заполнение листов
данными, работу с шаблонами, пагинацию, печать в PDF и вставку изображений.

- Клиентское Windows-приложение (WPF/WinForms) с установленным Microsoft Excel.
- Целевые фреймворки: `net472` и `net5.0-windows`.
- Стиль API: экземплярный класс с `IDisposable`, элементы fluent-билдера, пригоден для DI.
- Комментарии и XML-документация — на русском.

---

## 2. Технология и платформы
- Работа только через COM Interop (`Microsoft.Office.Interop.Excel`).
- Поддержка Excel 2007/2010/2016/2021; форматы .xls, .xlsx, .xlsm.
- Ссылка на PIA 15.x. Для старых версий Excel — fallback через late binding
  (`Type.GetTypeFromProgID("Excel.Application")` + `dynamic`), чтобы не тянуть разные PIA.
  Абстрагировать это внутренним слоем-обёрткой, публичный API от PIA не зависит.
- Сборка: `AnyCPU`. При несовпадении битности процесса и установленного Excel —
  понятное исключение `ExcelBitnessMismatchException` с инструкцией (или запуск отдельного
  процесса нужной битности). NuGet-пакет должен содержать сборки `x86` и `x64`
  с рантайм-селектором.
- Multi-target: `net472;net5.0-windows`. Для `net472` подключить NuGet `System.Text.Json`.
- Гарантированное освобождение COM: `try/finally`, `Marshal.FinalReleaseComObject`,
  подавление диалогов (`DisplayAlerts=false`, `AskToUpdateLinks=false`, `Visible=false`),
  корректное завершение процесса EXCEL.EXE. Никаких «висящих» EXCEL.EXE после Dispose.
- Запись массивов — одним вызовом `Range.Value2` (для производительности).

## 3. Публичный API (общая форма)
```csharp
using var excel = ExcelLibrary.Create()
    .FromTemplate(pathOrStream)        // или .New()
    .WithHiddenWorkFile(savePath)      // временный скрытый файл
    .WithPagination(o => o
        .SourceSheet("Таблица")
        .FirstPageTemplate("Для печати")
        .SubsequentTemplate("Шаблон листа")
        .HideServiceSheets(true))
    .Build();

excel.FillFromDataTable("Таблица", "A11", table, writeHeaders: false);
excel.FillFromArray("Лист1", "A1", data);            // object[,] или IEnumerable<T>
excel.FillFromJson("Лист1", json);                   // схема — см. п.4.1
excel.SetNamedValue("Version", "1");
excel.SetNamedValues(new Dictionary<string, object> { ["Author"] = "Иванов" });
excel.InsertImage("Лист1", "B2", imageBytes, widthPx: 120, heightPx: 80);
excel.SetPrintArea("Лист1", auto: true);
excel.SetHeaderFooter("Лист1", header: "...", footer: "...");
excel.SetPrintTitles("Лист1", rows: "1:2", columns: "A:B");
excel.Paginate();                                    // см. раздел 5
excel.ExportSheetToPdf("Лист1", pdfPath, overwrite: true,
                       quality: PdfQuality.High, includeMarkup: true);
excel.AddSheet("Новый", after: "Лист1");
excel.RemoveSheet("Лишний");
```

## 4. Функциональность

### 4.1 Заполнение из данных
- **DataTable**: заголовки по умолчанию писать (настраиваемо). `DBNull`/`null` → пустая ячейка.
  Все значения по умолчанию пишутся как текст (типизация — на следующем этапе).
- **Массив**: `object[,]` и `IEnumerable<T>`; запись одним куском через `Range.Value2`.
- **JSON** (System.Text.Json): две схемы —
  (а) массив объектов → один лист;
  (б) вложенная:
```json
{
  "sheets": [
    {
      "name": "Лист1",
      "startCell": "A1",
      "columns": ["A", "B", "C"],
      "data": [ { "A": "...", "B": 1, "C": true } ]
    }
  ]
}
```
  Модель схемы описать в коде и в README.

### 4.2 Именованные диапазоны
- Глобальные (scope = Workbook).
- Только одна ячейка.
- Перезаписывать существующие.
- Формулы не поддерживаются.
- API:
```csharp
void SetNamedValue(string key, object value);
void SetNamedValues(IDictionary<string, object> values);
```

### 4.3 Указание диапазона и переполнение
- Задаётся только верхняя левая ячейка.
- Если данные выходят за пределы существующего диапазона/страницы — бросать
  `ExcelRangeOverflowException`.

### 4.4 Шаблон и временный файл
- Загрузка: из пути к файлу **или** из `Stream`.
- Сценарий: шаблон копируется в скрытый временный файл рядом с целевым путём →
  заполняется → сохраняется в видимый файл. При любой ошибке до успешного сохранения
  временный файл удаляется.
- Сохранение формата `.xls/.xlsx/.xlsm` определять по расширению целевого файла.
- Добавление/удаление листов в шаблоне — см. п.4.8.

### 4.5 Изображения
- Источник: путь к файлу, `Stream`, `byte[]`.
- Встраивание в документ (после сохранения не требует исходника).
- Форматы: `.png`, `.jpg`, `.bmp`.
- Размер: в пикселях **или** относительно ячеек (enum `ImageSizeMode`).
- Привязка: `Placement = xlMoveAndSize`.
- Метод: `InsertImage(sheet, cell, source, size, anchor)`.

### 4.6 Печать, колонтитулы, область печати
- **Область печати**: `SetPrintArea(sheet, auto: true)` — автоподбор по фактическим данным.
  Для первой страницы пагинации — **всегда** из шаблона (не менять).
- **Колонтитулы**: чтение/запись `PageSetup.LeftHeader/CenterHeader/RightHeader`
  и `LeftFooter/CenterFooter/RightFooter`.
- **Повторение строк/столбцов**: `SetPrintTitles(sheet, rows, columns)` →
  `PageSetup.PrintTitleRows/PrintTitleColumns`.
- **Перенос настроек печати** с листа-шаблона на новые листы — **без буфера обмена**
  (только через свойства `PageSetup`: `Orientation`, `LeftMargin`, `RightMargin`,
  `TopMargin`, `BottomMargin`, `Zoom`, `FitToPagesWide`, `FitToPagesTall`,
  `PrintArea`, `PrintTitleRows`, `PrintTitleColumns`, `CenterHorizontally`,
  `LeftHeader`, `CenterHeader`, `RightHeader`, `LeftFooter`, `CenterFooter`,
  `RightFooter`).

### 4.7 Экспорт в PDF
- Метод: `ExportSheetToPdf(sheet, path, overwrite, quality, includeMarkup)`.
- Только один указанный лист (`Worksheet.ExportAsFixedFormat`).
- Существующий PDF перезаписывается.
- Уровень качества — параметр (`PdfQuality` enum или `int` 0–100) и флаг разметки.

### 4.8 Добавление/удаление листов
- `AddSheet(name, after)` — копирует стиль/настройки печати с листа-образца, если он задан.
- `RemoveSheet(name)` — с проверкой, что лист не является единственным и не защищён.

## 5. Пагинация печатных листов по шаблону (ключевой модуль)

### 5.1 Цель
Реализовать модуль `SheetPaginator`, который:
1. Принимает книгу с шаблонами и заполненный источник данных.
2. Разворачивает данные в N печатных листов:
   - первая страница — на основе «первого шаблона» (в файле — «Для печати»),
   - страницы 2..N — на основе «шаблона последующих страниц» (в файле — «Шаблон листа»),
   - каждая копия ссылается на свой непрерывный блок строк источника.
3. Корректно проставляет номер листа и связанные метаданные.
4. Опционально скрывает/удаляет служебные листы.

### 5.2 Наблюдения по приложенному файлу (использовать как референс)
- «Для печати» ссылается на `Таблица!A11…A38` — **28 строк** на первой странице.
- «Шаблон листа» ссылается на `Таблица!A2…A32` — **31 строка** на последующих страницах.
- Количества **разные** (28 vs 31). Алгоритм обязан **автоопределять**
  rows-per-page для каждого шаблона, а не хардкодить.
- В «Шаблон листа» есть формула номера листа `=((ROW(A1)-1-38)/35)+2`,
  в «Для печати» — `=Version`, `=KDNumber`, `=SheetsNumber` (глобальные имена).
- Позиции маркеров `«Подпись и дата»`, `«Инв. № дубл.»`, `«Взам. инв. №»`,
  `«Инв. № подл.»` сдвинуты между шаблонами → rows-per-page считать по количеству
  ячеек с `=Таблица!`, а не по номеру последней строки.
- Имя листа-шаблона в файле — **«Шаблон листа»**, в ТЗ — `template`.
  Делаем конфигурируемым, по умолчанию — брать из шаблона.

### 5.3 Конфигурация
```csharp
public sealed class PaginationOptions
{
    public string SourceSheetName { get; init; } = "Таблица";
    public string FirstPageTemplateSheetName { get; init; } = "Для печати";
    public string SubsequentTemplateSheetName { get; init; } = "Шаблон листа";

    public int? DataStartRowInSource { get; init; } = null;  // null = автоопределение
    public int? RowsPerFirstPage { get; init; } = null;       // null = автоопределение
    public int? RowsPerSubsequentPage { get; init; } = null;  // null = автоопределение

    public string OutputSheetNamePattern { get; init; } = "Лист {n}"; // {n} = номер страницы
    public bool HideServiceSheets { get; init; } = true;
    public string[] ServiceSheetsToHide { get; init; } =
        new[] { "Таблица", "Info", "Шаблон листа" };

    public bool RecalculateOnFinish { get; init; } = true;
    public string? SheetNumberCellAddress { get; init; } = null; // null = автоопределение
}
```

### 5.4 Автоопределение параметров (если параметр = null)
1. **DataStartRowInSource** — минимальный номер строки среди всех `=SourceSheet!<cell>`
   в шаблоне первой страницы. Для файла: 11.
2. **RowsPerFirstPage** — количество **уникальных строк** источника, на которые
   ссылается шаблон первой страницы. Для файла: 28 (A11–A38).
3. **RowsPerSubsequentPage** — то же для шаблона последующих страниц.
   Для файла: 31 (A2–A32).
4. **SheetNumberCellAddress** — ячейка с формулой/значением номера листа.
   Определять по маркеру «Лист» в соседней ячейке или по формуле вида
   `=((ROW(...)-...)/...)+...`. Для файла: S34 (маркер «Лист» в T33).

### 5.5 Алгоритм
1. Валидация:
   - обязательные листы существуют;
   - `RowsPerFirstPage > 0`, `RowsPerSubsequentPage > 0`;
   - источник данных начинается не выше `DataStartRowInSource`.
2. Прочитать общее число строк данных `T` из источника.
3. Посчитать распределение:
   - если `T <= RowsPerFirstPage` → только первая страница, копий шаблона нет;
   - иначе `remaining = T - RowsPerFirstPage`,
     `pagesSubsequent = ceil(remaining / RowsPerSubsequentPage)`,
     всего страниц `N = 1 + pagesSubsequent`.
4. Заполнить источник данными (если ещё не заполнен).
5. **Первая страница** — лист «Для печати» остаётся как есть, к нему применяются
   только настройки печати и `PrintArea`, заданные в шаблоне (не перезаписывать).
6. **Последующие страницы** — для `i = 1..pagesSubsequent`:
   1. Скопировать лист `SubsequentTemplateSheetName` **целиком**
      (`Worksheet.Copy(After: lastSheet)`, без буфера обмена).
   2. Присвоить имя по `OutputSheetNamePattern` (`{n}` = `i + 1`).
   3. Переписать все формулы `=SourceSheet!<cellRef>`:
      - распарсить `<cellRef>` (A11, B11, …, AB123; поддержать `$`-абсолютные ссылки);
      - вычислить новый номер строки:
        `newRow = firstRowOfPage(i + 1) + (originalRowIndex - minOriginalRow)`;
      - `firstRowOfPage(1) = DataStartRowInSource`;
      - `firstRowOfPage(p) = DataStartRowInSource + RowsPerFirstPage +
                            (p - 2) * RowsPerSubsequentPage` для `p >= 2`;
      - при переполнении (последняя страница) — очистить ячейки для строк,
        которых нет в источнике (не оставлять «висячих» ссылок на несуществующие строки).
   4. Переписать/проставить номер листа в `SheetNumberCellAddress`:
      - если в шаблоне была формула — заменить на аналогичную с корректным смещением,
        либо записать целое значение `i + 1` (приоритет — целое значение, если формула
        не поддаётся однозначному пересчёту);
      - в файле `S34` содержит `=((ROW(A1)-1-38)/35)+2` — эта формула сломается
        при копировании, её необходимо пересчитать или заменить значением.
   5. Перенести настройки печати с шаблона на копию **без буфера обмена**
      (см. п.4.6).
   6. `PrintArea` — автоподбор по фактически заполненным ячейкам копии.
7. После всех копий:
   - скрыть/удалить `ServiceSheetsToHide` (по флагу);
   - пересчитать (`Application.CalculateFull`), если `RecalculateOnFinish`.
8. Освободить COM-объекты по общим правилам библиотеки.

### 5.6 Что НЕ делать
- Не хардкодить `28`, `31`, `11`, `A2`, `A38` — всё вычисляется из шаблона.
- Не использовать `Worksheet.Copy` через буфер обмена (`Clipboard`) — только
  программный API `Worksheet.Copy(Before/After)`.
- Не переносить настройки печати через `PasteSpecial` — только через `PageSetup`.
- Не трогать глобальные именованные диапазоны (`Version`, `KDNumber`, `Author`,
  `CreationDate`, `SheetsNumber`) — их заполняет отдельный модуль.
- Не «угадывать» формулы, не относящиеся к источнику данных — оставлять как есть.

### 5.7 Пограничные случаи
- **Пустой источник данных** — только первая страница, копий нет.
- **Данные меньше одной страницы** — только первая страница.
- **Последняя страница не заполнена полностью** — лишние ячейки очищать
  (не оставлять ссылок на несуществующие строки).
- **Разное число строк на первой и последующих страницах** — норма (28 vs 31).
- **Объединённые ячейки в шаблоне** — `Worksheet.Copy` сохраняет их; при переписывании
  формул не объединять/разъединять ячейки.
- **Формулы, ссылающиеся на другие листы, кроме источника** — оставить без изменений.
- **Ошибка в середине пагинации** — удалить все созданные копии и временный файл.
- **Большие объёмы (1000+ страниц)** — предупредить/ограничить; отключить
  `ScreenUpdating`, `EnableEvents`, `Calculation` на время работы.

### 5.8 Взаимодействие с другими модулями
- **Именованные диапазоны** (`Version`, `KDNumber`, `Author`, `CreationDate`,
  `SheetsNumber`) заполняются **до** или **после** пагинации?
  Правило: `SheetsNumber` (общее число листов) должен выставляться **после**
  пагинации, остальные — **до**. Зафиксировать в README и в коде фасада.

## 6. Обработка ошибок и освобождение COM
- Все публичные методы бросают типизированные исключения библиотеки:
  `ExcelLibraryException` и наследники:
  `ExcelRangeOverflowException`, `ExcelTemplateException`,
  `ExcelBitnessMismatchException`, `ExcelPaginationException`.
- При ошибке во время записи/сохранения временный файл удаляется, COM-объекты
  освобождаются.
- `Dispose` должен быть идемпотентным и гарантировать завершение `EXCEL.EXE`,
  запущенного библиотекой (не трогая чужие экземпляры).

---

## 7. Производительность
- `Application.ScreenUpdating = false`, `EnableEvents = false`,
  `Calculation = xlCalculationManual` на всё время работы; восстанавливать в `finally`.
- Все формулы переписывать одним проходом по коллекции ячеек, не в цикле
  «ячейка → вызов COM».
- Запись значений — одним вызовом `Range.Value2`.

## 8. Ограничения текущего этапа (НЕ реализовывать)
- Типизацию ячеек (даты/числа/формулы) — всё пишется как текст.
- Формулы в именованных диапазонах.
- Unit/integration-тесты (следующий этап).

  шаблона: листы «Для печати», «Таблица», «Info», «Шаблон листа»; формулы пагинации
  и именованные ссылки (`Version`, `KDNumber`, `Author`, `SheetsNumber` и др.).

## 10. Критерии приёмки (объединённые)

### 10.1 Общие
1. После `Dispose` в диспетчере задач не остаётся процессов EXCEL.EXE, запущенных
   библиотекой.
2. Библиотека собирается под `net472` и `net5.0-windows`, работает в `AnyCPU`
   на x86- и x64-Excel.
3. При ошибке в середине записи временный файл удаляется, целевой не создаётся.
4. `SetNamedValue`/`SetNamedValues` перезаписывают существующие имена;
   многоячеечные диапазоны отклоняются.
5. `InsertImage` после сохранения и переноса файла на другой ПК отображает
   изображение (встроено в документ).
6. `ExportSheetToPdf` перезаписывает существующий файл, сохраняет разметку
   и учитывает параметр качества.

### 10.2 Пагинация (на приложенном шаблоне)
1. Для `T = 100` строк данных создаётся `1 + ceil((100-28)/31) = 4` печатных листа.
2. «Лист 2» ссылается на `Таблица!A39…A69` (31 строка),
   «Лист 3» — на `A70…A100`, «Лист 4» — на `A101…A131`
   (последняя страница с «хвостом», лишние ячейки очищены).
3. Номер листа в `S34` каждого печатного листа — 1, 2, 3, 4 соответственно
   (значением или корректной формулой).
4. `PageSetup` (ориентация, поля, масштаб, колонтитулы) на всех печатных листах
   совпадает с шаблоном.
5. `PrintArea` на каждом листе покрывает фактически заполненные данные.
6. Служебные листы («Таблица», «Info», «Шаблон листа») скрыты при
   `HideServiceSheets = true`.
7. `SheetsNumber` = 4 после пагинации.
8. При ошибке в середине пагинации все созданные копии и временный файл удалены,
   исходный шаблон не изменён.

## Открытые вопросы (агент должен либо спросить, либо принять дефолт)
1. Поведение последней страницы: очищать лишние ячейки (дефолт) или оставлять
   формулы со ссылками на пустые строки источника?
2. Способ простановки номера листа: значением `2, 3, 4…` (дефолт) или формулой?
3. Момент установки `SheetsNumber`: после пагинации (зафиксировано в п.5.8).
4. Формат `.xls`: если источник данных больше 65 536 строк — бросать
   `ExcelRangeOverflowException` (дефолт).
