# Задача
Разработать библиотеку на C# (LangVersion 9) для работы с Excel через COM Interop.
Библиотека должна инкапсулировать создание/закрытие COM-объектов, заполнение листов
данными, работу с шаблонами, печать в PDF и вставку изображений.

# Контекст использования
- Клиентское Windows-приложение (WPF/WinForms) с установленным Microsoft Excel.
- Целевые фреймворки: `net472` и `net5.0-windows`.
- Стиль API: экземплярный класс с `IDisposable`, элементы fluent-билдера, пригоден для DI.
- Комментарии и XML-документация — на русском.

# Технические ограничения
- Работа только через COM Interop (`Microsoft.Office.Interop.Excel`).
- Поддержка Excel 2007/2010/2016/2021; форматы .xls, .xlsx, .xlsm.
- Ссылка на PIA 15.x. Для старых версий Excel — fallback через late binding
  (`Type.GetTypeFromProgID("Excel.Application")` + `dynamic`), чтобы не тянуть разные PIA.
  Абстрагировать это внутренним слоем-обёрткой, публичный API от PIA не зависит.
- Сборка: `AnyCPU`. При несовпадении битности процесса и установленного Excel —
  понятное исключение с инструкцией (или запуск отдельного процесса нужной битности).
  NuGet-пакет должен содержать сборки `x86` и `x64` с рантайм-селектором.
- Multi-target: `net472;net5.0-windows`. Для `net472` подключить NuGet `System.Text.Json`.
- Гарантированное освобождение COM: `try/finally`, `Marshal.FinalReleaseComObject`,
  подавление диалогов (`DisplayAlerts=false`, `AskToUpdateLinks=false`, `Visible=false`),
  корректное завершение процесса EXCEL.EXE. Никаких «висящих» EXCEL.EXE после Dispose.
- Запись массивов — одним вызовом `Range.Value2` (для производительности).

# Публичный API (примерная форма)
```csharp
using var excel = ExcelLibrary.Create()
    .FromTemplate(pathOrStream)        // или .New()
    .WithHiddenWorkFile(savePath)      // временный скрытый файл
    .Build();

excel.FillFromDataTable("Таблица", "A2", table, writeHeaders: true);
excel.FillFromArray("Лист1", "A1", data);            // object[,] или IEnumerable<T>
excel.FillFromJson("Лист1", json);                   // схема — см. ниже
excel.SetNamedValue("Version", "1");
excel.SetNamedValues(new Dictionary<string, object> { ["Author"] = "Иванов" });
excel.InsertImage("Лист1", "B2", imageBytes, widthPx: 120, heightPx: 80);
excel.SetPrintArea("Лист1", auto: true);
excel.SetHeaderFooter("Лист1", header: "...", footer: "...");
excel.SetPrintTitles("Лист1", rows: "1:2", columns: "A:B");
excel.ExportSheetToPdf("Лист1", pdfPath, overwrite: true, quality: PdfQuality.High);
excel.AddSheet("Новый", after: "Лист1");
excel.RemoveSheet("Лишний");
```

# Функциональность
## 1. Заполнение из данных
 - **DataTable**: заголовки по умолчанию писать (настраиваемо). `DBNull/null` → пустая ячейка.
  Все значения по умолчанию пишутся как текст (типизация — на следующем этапе).
-  **Массив**: `object[,] `и `IEnumerable<T>`; запись одним куском через `Range.Value2`.
-  **JSON** (System.Text.Json): две схемы — 
   (а) массив объектов → один лист; (б) вложенная: `{ sheets: [ { name, startCell, columns, data: [...] } ] }`.
  Описать модель схемы в коде и в README.
-  **Указание диапазона**: только верхняя левая ячейка. Если данные выходят за пределы существующего диапазона/страницы — бросать `ExcelRangeOverflowException`.
-  **Именованные диапазоны** (глобальные, scope = Workbook):
   -  только одна ячейка;
   -  перезаписывать существующие;
   -  формулы не поддерживаются;
   -  методы: `SetNamedValue(string key, object value)` и `SetNamedValues(Dictionary<string, object>)`.

# 2. Шаблон
- Загрузка: из пути к файлу **или** из `Stream`.
- Сценарий: шаблон копируется в скрытый временный файл рядом с целевым путём → заполняется → сохраняется в видимый файл. При любой ошибке до успешного сохранения — временный файл удаляется.
- Добавление/удаление листов в шаблоне (см. API выше).
- Сохранение формата `.xls/.xlsx/.xlsm` определять по расширению целевого файла.

# 3. Пагинация по шаблону (ключевое!)
В шаблоне (см. приложенный файл) используются:
- лист **«Для печати»** — первая страница, ссылается на `Таблица!A11:A38` и т.д. (28 строк);
- лист **«Шаблон листа»** — формат для последующих страниц, ссылается на `Таблица!A2:A36` (35 строк на страницу);
- номер листа считается формулой `=((ROW(A1)-1-38)/35)+2`;
- лист «Info» — key-value параметры (в т.ч. `Количество листов в документе`, `Блок (да/нет)`);
- лист **«Таблица»** — источник данных, заполняется извне.

Имя листа-шаблона должно быть **конфигурируемым** (в файле — «Шаблон листа», в ТЗ — template), по умолчанию — брать из шаблона.

Требуется реализовать автогенерацию страниц по данным:

1. Заполнить лист-источник («Таблица») N строками.
2. Посчитать количество страниц: первая («Для печати») + `ceil(remaining / rowsPerTemplatePage)`.
3. Скопировать «Шаблон листа» нужное число раз **и переписать в копиях ссылки на лист-источник** на следующий блок строк (следующие 35 строк и т.д.). Формулы номера листа при этом должны продолжать считать корректно.
4. Скрыть/удалить служебные листы («Info», «Таблица», «Шаблон листа») при сохранении (настраиваемо флагом `HideServiceSheets`).

Структуру шаблона считать **произвольной**: агент не должен хардкодить имена листов кроме дефолтов, всё настраивается свойствами.

# 4. Печать
- **Область печати**: метод `SetPrintArea(sheet, auto: true)` — автоподбор по фактическим данным. Для первого листа — всегда из шаблона (не менять).
- **Колонтитулы**: чтение/запись `PageSetup.LeftHeader/CenterHeader/RightHeader` и `LeftFooter/CenterFooter/RightFooter`.
- **Повторение строк/столбцов**: `SetPrintTitles(sheet, rows, columns)` → `PageSetup.PrintTitleRows/PrintTitleColumns`.
- **Перенос настроек печати** с листа-шаблона на новые листы — **без буфера обмена** (только через свойства `PageSetup` и `PageSetup`-объекты: `Orientation`, `LeftMargin`, `RightMargin`, `TopMargin`, `BottomMargin`, `Zoom`, `FitToPagesWide`, `FitToPagesTall`, `PrintArea`, `PrintTitleRows`, `PrintTitleColumns`, `CenterHorizontally` и т.д.).
- **PDF**: `ExportSheetToPdf(sheet, path, overwrite, quality, includeMarkup)`. 
  - только один указанный лист (`Worksheet.ExportAsFixedFormat`);
  - существующий PDF перезаписывается;
  - уровень качества — параметр (`PdfQuality` enum или `int` 0–100) и флаг разметки.
  

# 5. Изображения
- Источник: путь к файлу, `Stream`, `byte[]`.
- Встраивание в документ (после сохранения не требует исходника).
- Форматы: `.png`, `.jpg`, `.bmp`.
- Размер: в пикселях **или** относительно ячеек (enum `ImageSizeMode`).
- Привязка: `Placement = xlMoveAndSize`.
- Метод: `InsertImage(sheet, cell, source, size, anchor)`.

# 6. Обработка ошибок и очистка
- Все публичные методы бросают типизированные исключения библиотеки (`ExcelLibraryException` и наследники: `ExcelRangeOverflowException`, `ExcelTemplateException`, `ExcelBitnessMismatchException` и т.д.).
- При ошибке во время записи/сохранения временный файл удаляется, COM-объекты освобождаются.
- `Dispose` должен быть идемпотентным и гарантировать завершение `EXCEL.EXE`, запущенного библиотекой (не трогая чужие экземпляры).

- Формулы в именованных диапазонах.

# Подзадача: пагинация печатных листов по шаблону

## Цель
Реализовать в библиотеке модуль `SheetPaginator`, который:
1. Принимает книгу с шаблонами и данные (DataTable/массив/JSON).
2. Заполняет источник данных (по умолчанию лист «Таблица»).
3. Разворачивает данные в N печатных листов:
   - первая страница — на основе «первого шаблона» (в файле — «Для печати»),
   - страницы 2..N — на основе «шаблона последующих страниц» (в файле — «Шаблон листа»),
   - каждая копия ссылается на свой непрерывный блок строк источника.
4. Корректно проставляет номер листа и связанные метаданные.
5. Опционально скрывает/удаляет служебные листы.

## Входные данные
- `Workbook` с листами:
  - источник данных — по умолчанию `Таблица`;
  - шаблон первой страницы — по умолчанию `Для печати`;
  - шаблон последующих страниц — по умолчанию `Шаблон листа`;
  - прочие служебные листы (`Info` и т.п.) — не трогать, кроме опционального скрытия.
- Заполненный лист-источник (или `DataTable`/массив, который заполняется до пагинации).

## Конфигурация (все имена — настраиваемые свойства)
```csharp
public sealed class PaginationOptions
{
    public string SourceSheetName { get; init; } = "Таблица";
    public string FirstPageTemplateSheetName { get; init; } = "Для печати";
    public string SubsequentTemplateSheetName { get; init; } = "Шаблон листа";

    public int? DataStartRowInSource { get; init; } = null;  // null = автоопределение
    public int? RowsPerFirstPage { get; init; } = null;       // null = автоопределение
    public int? RowsPerSubsequentPage { get; init; } = null;  // null = автоопределение

    public string OutputSheetNamePattern { get; init; } = "Лист {n}"; // {n} = номер страницы
    public bool HideServiceSheets { get; init; } = true;
    public string[] ServiceSheetsToHide { get; init; } =
        new[] { "Таблица", "Info", "Шаблон листа" };

    public bool RecalculateOnFinish { get; init; } = true;
    public string? SheetNumberCellAddress { get; init; } = null; // null = автоопределение
}
```

## Автоопределение параметров (обязательно, если параметр = null)
1. **DataStartRowInSource** — минимальный номер строки среди всех `=SourceSheet!<cell>` в шаблоне первой страницы. Для приложенного файла: 11.
2. **RowsPerFirstPage** — количество уникальных строк источника, на которые ссылается шаблон первой страницы. Для приложенного файла: 28 (A11–A38).
3. **RowsPerSubsequentPage** — то же для шаблона последующих страниц. Для приложенного файла: 31 (A2–A32). 
4. **SheetNumberCellAddress** — ячейка в шаблоне, содержащая формулу/значение номера листа. Определять по маркеру «Лист» в соседней ячейке или по формуле вида `=((ROW(...)-...)/...)+....` Для приложенного файла: S34 (в шаблоне есть «Лист» в T33 и формула в S34).



## Алгоритм
1. Валидация:
    - обязательные листы существуют;
    - `RowsPerFirstPage > 0`, `RowsPerSubsequentPage > 0`;
    - источник данных начинается не выше `DataStartRowInSource`.
2. Прочитать общее число строк данных `T` из источника.
3. Посчитать распределение:

если T <= RowsPerFirstPage → только первая страница, копий шаблона нет;

иначе remaining = T - RowsPerFirstPage,
pagesSubsequent = ceil(remaining / RowsPerSubsequentPage),
всего страниц N = 1 + pagesSubsequent.

4. Заполнить источник данными (если ещё не заполнен).
5. **Первая страница** — лист «Для печати» остаётся как есть, к нему применяются только настройки печати и `PrintArea`, заданные в шаблоне (не перезаписывать).
6. Последующие страницы — для i = 1..pagesSubsequent:
   1. Скопировать лист `SubsequentTemplateSheetName` целиком (без буфера обмена — через `Worksheet.Copy(After: lastSheet)`).
   2. Присвоить имя по `OutputSheetNamePattern` (`{n}` = `i + 1`).
   3. Переписать все формулы `=SourceSheet!<cellRef>`:
      - распарсить `<cellRef>` (A11, B11, …, AB123; поддержать `$`-абсолютные ссылки);
      - вычислить новый номер строки: `newRow = firstRowOfPage(i + 1) + (originalRowIndex - minOriginalRow)`.
      - `firstRowOfPage(1) = DataStartRowInSource`;
      - `firstRowOfPage(p) = DataStartRowInSource + RowsPerFirstPage + (p - 2) * RowsPerSubsequentPage` для p >= 2;
      - при переполнении (последняя страница) — оставить пустые ячейки для строк, которых нет в источнике (не оставлять «висячих» ссылок на несуществующие строки).

   4. Переписать/проставить номер листа в `SheetNumberCellAddress`:
        - если в шаблоне была формула — заменить на аналогичную с корректным смещением, либо записать целое значение `i + 1` (приоритет — целое значение, если формула не поддаётся однозначному пересчёту);
        - в приложенном файле `S34` содержит `=((ROW(A1)-1-38)/35)+2` — эта формула сломается при копировании, её необходимо пересчитать или заменить значением.
    5. Перенести настройки печати с шаблона на копию без буфера обмена: **PageSetup** (Orientation, Margins, Zoom, FitToPagesWide/Tall, PrintTitleRows/Columns, PrintArea, CenterHorizontally, Header/Footer).
    6. `PrintArea` — автоподбор по фактически заполненным ячейкам копии.
7. После всех копий:
    - скрыть/удалить `ServiceSheetsToHide` (по флагу);
    - пересчитать (`Application.CalculateFull`), если `RecalculateOnFinish`.
8. Освободить COM-объекты по общим правилам библиотеки.

## Что **НЕ** делать
- Не хардкодить `28`, `31`, `11`, `A2`, `A38` — все значения вычисляются из шаблона.
- Не использовать `Worksheet.Copy` через буфер обмена (`Clipboard`), только через программный API `Worksheet.Copy(Before/After)`.
- Не переносить настройки печати через `PasteSpecial` — только через `PageSetup`.
- Не трогать глобальные именованные диапазоны (`Version`, `KDNumber`, `Author`, `CreationDate`, `SheetsNumber` и т.п.) — они управляются отдельно через модуль именованных диапазонов.
- Не пытаться «угадать» формулы, не относящиеся к источнику данных — оставлять как есть.

## Пограничные случаи
- Пустой источник данных — только первая страница, копий нет.
- Данные меньше одной страницы — только первая страница.
- Последняя страница не заполнена полностью — оставшиеся ячейки должны ссылаться на пустые строки источника (или быть очищены), а не на несуществующие строки.
- Разное число строк на первой и последующих страницах — не ошибка, а норма (см. приложенный файл: 28 vs 31).
- В шаблоне есть объединённые ячейки — `Worksheet.Copy` сохраняет их; при переписывании формул не объединять/разъединять ячейки.
- В шаблоне есть формулы, ссылающиеся на другие листы, кроме источника — оставить без изменений.
- Ошибка в середине пагинации — удалить все уже созданные копии и временный файл (см. общие правила библиотеки).
- Большие объёмы (1000+ страниц) — предупредить/ограничить, отключить `ScreenUpdating`, `EnableEvents`, `Calculation` на время работы.
  

## Производительность
- `Application.ScreenUpdating = false`, `EnableEvents = false`, `Calculation = xlCalculationManual` на всё время пагинации.
- Все формулы переписывать одним проходом по коллекции ячеек, не в цикле «ячейка → вызов COM».
- Запись значений источника — одним вызовом `Range.Value2`.

## Критерии приёмки (на приложенном файле)
1. Для `T = 100` строк данных создаётся `1 + ceil((100-28)/31) = 1 + 3 = 4` печатных листа.
2. Лист «Лист 2» ссылается на `Таблица!A39…A69` (31 строка), «Лист 3» — на `A70…A100`, «Лист 4» — на `A101…A131` (последняя страница с «хвостом», лишние ячейки пустые или очищены).
3. Номер листа в S34 каждого печатного листа — 1, 2, 3, 4 соответственно (значением или корректной формулой).
4. Настройки `PageSetup` (ориентация, поля, масштаб) на всех печатных листах совпадают с шаблоном.
5. `PrintArea` на каждом листе покрывает фактически заполненные данные.
6. Служебные листы («Таблица», «Info», «Шаблон листа») скрыты (если `HideServiceSheets = true`).
7. После `Dispose` нет висящих `EXCEL.EXE`.
